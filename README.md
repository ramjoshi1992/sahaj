# Lull

Generative music that assembles itself for the hour, the weather and where you
are. Every session is built at playback time from a measured library — no two
are the same, and none exists as a file.

## How it works

A session is three **movements**, one per seed family. Each opens with its seed
track, cycles that family's three middle pieces, and closes with the same seed.
A piece never appears outside its own movement, so the only joins between
unrelated material are the two movement boundaries — and those are sequential,
with a breath of near-silence, never a crossfade.

Underneath runs a **texture bed** — rain, birdsong, a fire — placed by measured
band overlap rather than a fixed percentage, and behind everything is the real
sky, computed from solar position for the listener's location and minute.

## Layout

    sequencer.js          library + mood/tier/duration -> a session plan
    engine.js             plays a plan, sample-accurate, with the texture bed
    bedlevel.js           how loud the bed sits, from measured properties
    sky.js                sun position, sky gradient, real star positions
    library.json          the runtime artefact: every piece, measured
    credits.json          third-party sources and their licences

    build_library.py      builds library.json from the audio
    calibrate_textures.py measures textures and group music (K-weighted)
    retexture.py          builds texture loops from source recordings
    upload_seeds.py       pushes seed tracks to R2
    check_licences.py     verifies Freesound licences from the API
    provenance.py         generates PROVENANCE.md

    generate_mood.py      the Lyria/ElevenLabs generation pipeline
    prompt_library.py     every prompt, written by hand
    stem_analyser.py      finds the conditioning anchor in a seed

    legacy/               superseded work, kept deliberately
    ss_output_sessions/   audition renders — the listening record

## Running it

    pip install -r requirements.txt
    cp .env.example .env        # then fill it in
    python -m http.server 8000  # the bench needs http, not file://

Audio lives on Cloudflare R2 and is not in this repository — it is over a
gigabyte, and `assets/` is gitignored along with `.env`.

## Hosting

- **GitHub Pages** — the frontend, static
- **Render** — the Flask API: accounts, sessions, reflections, stats
- **Neon** — Postgres. Render's free tier deletes databases after 30 days
- **Cloudflare R2** — 252 audio pieces and 14 texture beds

The API is deliberately off the critical path. A session starts, plays and ends
without it; it is only called to save what happened.

## Provenance and rights

See `PROVENANCE.md`, generated by `provenance.py`. Texture beds are Creative
Commons recordings from Freesound — three require attribution, which is carried
in `library.json` and shown in the app.
